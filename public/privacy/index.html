Privacy

原文件留在浏览器，连接信息由你控制。

这里说明拾词实际会处理什么、不会保存什么，以及第三方服务何时会收到数据。

数据流向

上传文档、图片与字幕

PDF、DOCX、TXT、Markdown 以及 SRT、VTT、ASS、SSA 字幕都在浏览器中提取或清洗文字；PNG、JPG、WEBP 和 BMP 图片使用网站自带的英文 OCR 在浏览器本地识别。原文件、原图与字幕文件不会上传到拾词服务器。扫描版 PDF 暂不支持 OCR。

音乐搜索与识别

歌名或歌手搜索词会通过拾词服务器发送给 Apple 的公开歌曲目录。你选择的本地音频会先在浏览器解码并生成 30 秒以内的 WAV 分片；完整原文件不会上传。开始识别后，分片才会通过拾词服务器发送给你选择的千问、硅基流动、OpenAI 或 Groq。

视频识别

原视频保留在当前浏览器，不会作为完整文件上传。启用语音识别时，浏览器从视频中解码音轨并生成 WAV 分片，再发送给你选择的语音服务商；启用画面识别时，浏览器按间隔截取画面下方区域并在本地运行英文 OCR，画面不会发送给模型服务商。合并文字通过一次性 sessionStorage 带到工作台。

字幕工作台交接

整理后的英文台词会暂存在当前标签页的 sessionStorage 中，并在打开工作台后立即读取和删除。只有你随后点击分析，整理后的文字才会发送给所选模型。

AI 分析

只有你点击分析后，待分析文字、筛选目标和数量才会通过拾词服务器发送给所选模型服务商。免费模式发送给站长接入的 DeepSeek；自有 API 模式发送给你选择的服务商。一周免费体验仅用于文字筛词，不包含音乐或视频语音转写费用。

API Key 与墨墨 Token

默认开启“在此浏览器记住连接”时，文本模型 API Key、语音模型 API Key、所选模型和墨墨 Token 保存在当前浏览器的 localStorage 中。关闭后仅保存在当前标签页的 sessionStorage 中。“清除”按钮会删除对应连接。请求时密钥会经过 Vercel 函数转发，但本站不写入数据库，也不主动记录请求正文。

一周免费体验

首次成功生成生词后开始连续计时 7×24 小时，期间不限文字分析次数。开始时间通过签名的 HttpOnly Cookie 记录，内容不包含身份资料。

第三方服务

Apple 歌曲目录、模型服务商和墨墨会依据各自条款处理收到的数据。请不要提交含有敏感个人信息、未公开研究数据或无权处理的内容。

拾词是个人开发的非官方工具，与 Apple、墨墨背单词及模型服务商不存在隶属或官方合作关系。请只处理你合法获得且有权用于个人学习的材料、字幕、音频和视频。

即时翻译的数据处理

只有点击“开始翻译”后，输入的单词或句子才会通过拾词服务器发送给免费体验模型或你已保存的模型服务商。输入内容与翻译结果不会写入本站数据库，结果只保留在当前页面。成功使用免费模型翻译也会开启或使用同一段连续 7 天体验期。

候选生词与同步记录

候选生词箱和“曾同步”标记保存在当前浏览器的 localStorage 中，用于跨页面收藏、自动合并和同步前提醒，不会写入本站数据库。它只记录本浏览器经拾词同步过的词，不代表墨墨账号的完整历史；清除浏览器数据会同时删除这些记录。
