Privacy

原文件留在浏览器，连接信息由你控制。

这里说明拾词实际会处理什么、不会保存什么，以及第三方服务何时会收到数据。

数据流向

上传文件

PDF、DOCX、TXT 和 Markdown 在浏览器中提取文字，原文件不会上传到拾词服务器。扫描版 PDF 暂不支持 OCR。

AI 分析

你点击分析后，提取的文字、筛选目标和数量会通过拾词服务器发送给所选模型服务商。免费模式发送给站长接入的 DeepSeek；自有 API 模式发送给你选择的服务商。

API Key 与墨墨 Token

默认开启“在此浏览器记住连接”时，API Key、所选模型和墨墨 Token 保存在当前浏览器的 localStorage 中，重新打开网站后会自动恢复。关闭该选项后，凭据仅保存在当前标签页的 sessionStorage 中，关闭标签页后清除。“清除”按钮会删除两处数据。请求时密钥会经过 Vercel 函数转发，但本站不写入数据库，也不主动记录请求正文。请勿在公共设备上开启持久保存。

免费次数

免费次数通过签名的 HttpOnly Cookie 记录，保存一年，内容只有已使用次数及防篡改签名，不包含身份资料。

第三方服务

模型服务商和墨墨会依据各自条款处理收到的数据。请不要提交含有敏感个人信息、未公开研究数据或无权处理的内容。

拾词是个人开发的非官方工具，与墨墨背单词及模型服务商不存在隶属或官方合作关系。
