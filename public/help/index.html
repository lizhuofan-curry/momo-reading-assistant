Help

失败时，先看是哪一步出了问题。

拾词会区分文件解析、图片识别、字幕清洗、模型连接、AI 输出和词本同步错误。你的当前文字和筛选结果不会因为一次失败自动清空。

文件与图片

图片没有识别出文字

请使用清晰、正向、对比度高且英文文字较大的图片。首次识别要加载约十几 MB 的本地资源，请等待进度完成。识别结果会显示在编辑框中，可在筛词前修正。

PDF 没有文字

扫描版 PDF 本质上是多页图片，目前请将需要的页面导出为图片上传，或复制正文后粘贴。

文件太大

单个文件或图片最多 25 MB；字幕文件最多 10 MB；PDF 每次最多读取 60 页；送入分析的文字最多 150,000 字符。

美剧字幕

字幕清洗后没有台词

确认文件包含英文，并使用 SRT、VTT、ASS、SSA 或 TXT。图片字幕和视频画面不能在这个页面直接识别。

能粘贴视频网站链接吗

不能。拾词不搜索或下载影视资源，也不绕过登录或 DRM。请上传你合法获得并有权用于个人学习的字幕文件。

为什么合并了两句

“合并被切开的短句”只处理相邻 1.5 秒内、语义明显未结束的字幕。若原字幕切分特殊，可以关闭该选项重新整理。

AI 分析

一周体验结束

前往连接设置添加自己的 API，即可继续使用。自有 API 不受免费体验时间限制。

模型连接失败

检查 Key、模型名称、余额和服务商区域。先在连接页面点击“测试连接”，成功后再回工作台。

词本同步

Token 无效

重新获取墨墨开放平台 Access Token，并在当前标签页重新测试。本站不会使用站长的 Token 替你同步。

找不到新词本

同步成功后，在墨墨 App 的云词本搜索中查找创建时填写的名称。

体验与费用

什么时候开始计时

首次使用免费模型成功生成生词后，开始连续 7×24 小时计时。分析失败、上传文件、字幕清洗、图片 OCR、测试连接和查看示例均不会开始计时；体验开始后，这些操作也不会延长结束时间。

体验期间有次数限制吗

没有。连续 7 天体验期内可以不限次数使用免费分析模型。

自有 API 是否收费

拾词不另外收费；模型调用费用与额度由你选择的服务商决定。
