Help

失败时，先看是哪一步出了问题。

拾词会区分文件解析、模型连接、AI 输出和词本同步错误。你的当前文字和筛选结果不会因为一次失败自动清空。

文件读取

PDF 没有文字

扫描件本质是图片。请换用可复制文字的版本，或复制正文后粘贴。

文件太大

单个文件最多 25 MB；PDF 每次最多读取 60 页；送入分析的文字最多 150,000 字符。

AI 分析

免费次数用完

前往连接设置添加自己的 API。自有 API 不消耗免费次数。

模型连接失败

检查 Key、模型名称、余额和服务商区域。先在连接页面点击“测试连接”，成功后再回工作台。

词本同步

Token 无效

重新获取墨墨开放平台 Access Token，并在当前标签页重新测试。本站不会使用站长的 Token 替你同步。

找不到新词本

同步成功后，在墨墨 App 的云词本搜索中查找创建时填写的名称。

额度与费用

免费 5 次怎么算

只有成功生成生词才扣除一次。测试连接、读取文件和查看示例都不扣次数。

自有 API 是否收费

拾词不另外收费；模型调用费用与额度由你选择的服务商决定。
